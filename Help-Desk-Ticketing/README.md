Help Desk Ticketing Lab
Platform: Spiceworks Cloud Help Desk
Setup
Created free Spiceworks account.
Configured help desk with organization name JPerkins IT Support.
Created 10 contacts representing end users.
Created, documented, and resolved 10 realistic IT support tickets.
Tickets Resolved
Ticket 1: Password reset for user unable to log in after vacation. Reset password in Active Directory. User access restored.
Ticket 2: Shared printer offline affecting multiple users. Cleared print queue and restarted print spooler. Printer operational.
Ticket 3: New hire account setup. Created user account in Active Directory with appropriate group permissions. New hire notified of credentials.
Ticket 4: Workstation running slowly. Disabled startup programs and cleared temporary files. Performance restored.
Ticket 5: No network connectivity after desk move. Identified loose ethernet cable and reseated. Network access restored.
Ticket 6: Account lockout after failed login attempts. Verified identity, unlocked account, reset password, and educated user on password policy.
Ticket 7: Software installation request for Microsoft Excel. Verified license, confirmed with manager, installed and verified functionality.
Ticket 8: Outlook disconnected. Removed and re-added email account in Outlook settings. Full email functionality restored.
Ticket 9: Second monitor showing no signal. Corrected display settings from disabled to extended. Monitor fully functional.
Ticket 10: USB device not recognized. Reinstalled USB root hub driver through Device Manager. Device recognized successfully.
