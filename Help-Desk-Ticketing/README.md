# Help Desk Ticketing Lab

## Setup
Created a free Spiceworks Cloud Help Desk account and added 10 contacts to represent end users.

## Tickets
- Password reset after vacation — reset in AD, user logged in successfully.  
- Shared printer offline - cleared queue and restarted spooler.  
- New hire account setup — created AD account with group permissions.  
- Slow workstation — disabled startup programs, cleared temp files.  
- No network after desk move — reseated loose ethernet cable.  
- Account lockout — unlocked account, reset password, explained policy.  
- Excel install — verified license, installed, tested.  
- Outlook disconnected — re-added account, restored email.  
- Second monitor no signal — fixed display settings.  
- USB not recognized — reinstalled USB root hub driver.

## Notes
A lot of issues came down to communication. For example, the Outlook case was really a password change the user hadn’t updated.  

## What I Learned
Help desk work is about troubleshooting *and* explaining fixes clearly. Documenting each ticket helped me practice both.
