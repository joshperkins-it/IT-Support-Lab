IT Support Lab
About This Portfolio
This repository documents my hands on IT support practice built entirely from scratch using free tools. It covers Active Directory user management, help desk ticket resolution, and Windows environment troubleshooting.
Tools Used
VirtualBox on macOS for Windows 10 virtual machine
AWS EC2 for Windows Server and Active Directory
Spiceworks Cloud Help Desk for ticket management
GitHub for portfolio documentation
Projects

Windows 10 Virtual Machine

Built a Windows 10 virtual machine using VirtualBox on macOS. Practiced file system navigation, user account management, command prompt commands including ipconfig, ping, and systeminfo, and hardware identification through Device Manager and Task Manager.

Active Directory Lab

Launched a Windows Server 2019 EC2 instance on AWS. Promoted it to a domain controller using PowerShell. Practiced creating, modifying, disabling, enabling, and deleting user accounts and groups in Active Directory. Practiced password resets and account unlocks.

Help Desk Ticketing

Set up a Spiceworks Cloud help desk. Created and resolved 10 realistic IT support tickets covering password resets, printer issues, network connectivity, account lockouts, software installation, email troubleshooting, display issues, and hardware problems. Documented each ticket with full troubleshooting steps and resolutions.
